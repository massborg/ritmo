# Ritmo Running: 100 Instagram cards

All cards are 1080 x 1350 (4:5) PNGs in `png/`. They follow the same rules as the first 12 posts: no emoji, no launch date, prices, user numbers, testimonials or named people, and Garmin is not mentioned. #maltarunning is in every hashtag set.

The order alternates a colour card (orange or graphite) with a light card, so the grid stays balanced if you post them in order. Paste the hashtags as the last paragraph of the caption, or as the first comment.

Waitlist cards point to ritmorunning.run (the waitlist website). Make sure the bio link is set to https://ritmorunning.run before posting them.
