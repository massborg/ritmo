# Ritmo Running: 100 Instagram cards

- `png/`: 100 cards, 1080 x 1350 (4:5), numbered card-001 to card-100.
- `captions.md`: caption, hashtags and alt text for every card.
- `calendar.md`: a suggested schedule, one card every 3 days from Monday 4 January 2027 (straight after post 12).
- `cards.json`: the same captions, hashtags, alt text and dates in a form that scheduling tools or Claude in Chrome can read.
- `contact-sheet.png`: all 100 on one page.

What's in it:

| Type | Cards |
|---|---|
| Coach's notes | 22 |
| Training tips (lists) | 17 |
| Running words (glossary) | 15 |
| Myth vs fact | 12 |
| Feature glimpses | 10 |
| By the numbers | 8 |
| Questions for the comments | 8 |
| Waitlist | 8 |

Rules followed: no emoji, no launch date, prices, user numbers, testimonials or named people, and no Garmin mentions. #maltarunning is in every hashtag set.
Cards alternate a colour card (orange or graphite) with a light card, so the grid stays balanced when posted in order.
Waitlist cards send people to ritmorunning.run or "the link in bio". Set the bio link to https://ritmorunning.run before posting them.
